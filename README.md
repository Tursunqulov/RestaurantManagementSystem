# RestaurantManagementSystem
we used JDK 21 version for stability. It is a maven project

To run the project, first create a local MySQL database named "restaurant_db" and import the "schema.sql" file located in "src/main/resources/db/". Then configure your database credentials using the "DB_USER" and "DB_PASS" environment variables. After that, open the project in your IDE or terminal and run:

mvn clean compile javafx:run

Use the default accounts generated by the SQL script to log into the system and explore the different dashboards.
